読み聞かせ×会話エージェントの研究

絵本の読み聞かせに、問いかける会話エージェントを加えると、親子の会話はどう変わるのか。

生成AIゲーム・XR
実験の様子の写真、またはエージェント画面

きっかけ

読み聞かせは、親子の会話が自然に生まれる大切な時間です。子どもに問いかけながら読む「ダイアロジックリーディング」という方法がありますが、毎回それを続けるのは、親にとって負担が大きい。そこで、問いかけ役をエージェントに手伝ってもらえないかと考えました。

つくったもの

問いかけ方の違う、2つの会話エージェントをつくりました。

物語関連型
絵本の内容について問いかける
日常会話型
子どもの生活や経験につなげて問いかける

やったこと

3〜10歳の子どもを持つ12組の親子に、エージェントなし・物語関連型・日常会話型の3つの条件で読み聞かせをしてもらい、会話の量と中身を比べました。

わかったこと

どちらのエージェントでも、親子の会話時間はエージェントなしより増えました。会話の中身は、問いかけ方で分かれました。日常会話型では親と子が交互に話を広げ、気持ちを言葉にする場面が多く出ました。物語関連型では、親が子どもの答えを支える形の対話が多く見られました。

いまは会話の様子を観察・記述した段階で、学習効果や親子関係への長期的な効果までは主張していません。

越境の視点から

ゲームとXRで培った「人を夢中にさせる仕掛け」を、子どもと親の時間に持ち込んだ研究です。教育で使った仕組みは、企業の研修や地域の取り組みにも活かせると考えています。
