## 【1】ヒーロー画面（まずこれ）

```
あなたはWebのアートディレクターです。個人サイトのコンセプトデザイン（ヒーロー画面）を1枚作ってください。

# サイト
日本人の起業家・エンジニアの個人サイト（日本語）。
XR・デジタルツイン・生成AI・ゲーミフィケーションで、産業現場（製造・建設）と行政のDXをつくっている人。
研究者然としたサイトではなく「実際に作っている人」のサイト。

# コンセプト：「工房」
作業台の上に、作ったものと測った数字が並んでいる — という佇まい。
明るく、読みやすく、開かれている。
「技術は特別な人のものではなく共通言語である」という思想を、デザインそのもので表現する。

# カラー（厳守）
- 背景: オフホワイト #FAFAF8
- 本文: #1A1A1A / 副次テキスト: #6B6B6B
- 罫線: #E5E3DE の細い線（製図・方眼のニュアンスをごく控えめに）
- アクセント: 1色のみ。彩度は抑えめ。落ち着いたインクブルーか深い緑あたりを提案してほしい

# 絶対にやらないこと
- 黒背景・ダークテーマ
- ネオン、グロー、発光表現
- 抽象的なCG（光る幾何学模様、パーティクル、ワイヤーフレーム、宇宙的な背景）
- グラデーションの多用
- AIサイトビルダーのテンプレートに見える構成

# 技術（XR・デジタルツイン・AI）の表現方法（重要）
この人はXR・デジタルツイン・生成AIの専門家ですが、それを「未来的な演出」で表現しないでください。
「実物」で表現します。

使ってほしい表現:
- 点群データ / フォトグラメトリの実際の画面
- 3D都市モデル（PLATEAU）のビューア画面
- BIM/CIMの建設モデル
- Unityなど開発ツールのエディタ画面
- VRヘッドセットを着けて作業している現場の人（工場・建設現場）
- AIアバターとの対話画面

使わないでほしい表現:
- 未来的な抽象CG、光るネットワーク図、ホログラム風の演出

イメージ: 工房の作業台の上に、点群データと3Dモデルとヘッドセットが実際に置かれている。
「これから作る未来」ではなく「すでに作ったもの」が並んでいる状態。

# レイアウト
- 上部にシンプルな横並びナビ（左にロゴタイプ、右に少数のメニュー）
- 大きな日本語の見出し2行（左寄せ）
- その下に小さめのサブコピー1行
- さらにその下に「技術タグ帯」を横一列（細い枠線、または薄い背景のピル型。目立たせすぎない）
- 右側または下に、実物のビジュアルを1枚（人物のポートレート、または上記の実物画面）
- 余白は広く。情報密度で圧迫しない

# タイポグラフィ
- 日本語が主役。日本語の可読性を最優先
- 欧文だけ大きく格好よく、日本語が小さい添え物、という構成にしない
- 見出しはゴシック体。線が細すぎず、太すぎず

# 入れる文言（レイアウトの参考として）
これは個人の名刺サイトです。スローガンやキャッチコピーは置かず、名前を主役にしてください。
上から順に、名前 → 肩書 → 説明1行 → 技術タグ帯 と並べます。

　清水 啓太郎
　Keitaro Shimizu

　株式会社Play Life Studio 代表取締役 CEO

　産業現場と行政に、XR・デジタルツイン・AIを実装しています。

技術タグ帯:
　XR / VR・AR　｜　デジタルツイン / BIM・CIM・PLATEAU　｜　生成AI・対話エージェント　｜　ゲーミフィケーション

ナビ: Works / About / Career / Contact

※ ヒーローに勤務先や大学名を並べないでください（経歴セクションにのみ記載します）

# 参考にしてほしい空気感
建築設計事務所のポートフォリオサイト、工房・アトリエ、製図。
参考にしないでほしいもの: AIスタートアップのLP、SaaSのダークテーマ、Framerのテンプレート。

# 出力
デスクトップ表示（16:9）のフルスクリーンショット風に。
まず1案作り、その後トーンの違う案をあと2つ出してください。
```

## 【2】Works セクション（このサイトの主役）

```
同じデザインシステム（背景 #FAFAF8 / 本文 #1A1A1A / 罫線 #E5E3DE / アクセント1色 /
抽象CG禁止 / 実物写真主義）で、実績セクションのコンセプトデザインを作ってください。

# 要件
- このサイトで最も大きく、最も重要なセクション
- 実績カードを4件。1件ずつゆったり大きく見せる（小さいカードを詰め込まない）
- 各カード: 実物のビジュアル + 件名 + 2行の説明 + 数字を1行入れる枠
- 数字の枠は今は空でよい（プレースホルダとして枠だけ見せる。勝手に数値を入れないこと）

# 各カードのビジュアル（すべて「実物」で）
1. Samurai Training — 産業現場の導入・オンボーディングOS
   → 工場や建設現場で、作業者がタブレットやVRヘッドセットで研修を受けている場面
2. XRFlowBuilder — XR・AI研修コンテンツの制作プラットフォーム
   → 実際の制作ツールのエディタ画面（ノードやシナリオを組んでいるUI）
3. PLATEAU SDK-Toolkits for Unity — 国交省3D都市モデルのオープンソースツールキット
   → 3D都市モデルをUnityのエディタ上で扱っている画面
4. 千葉県 インフラDXアドバイザー — BIM/CIM・ICT施工の現場普及と職員研修
   → 建設現場のBIM/CIMモデル、または点群データと現場写真の対比

未来的な演出やグロー表現は使わず、実際の画面・実際の現場として描いてください。

# 出力
デスクトップ表示。スクロールした状態の1画面として。
```

## 【3】（任意）先に言葉で詰めたい場合

```
以下のコンセプトに基づいて、Webサイトのデザインシステムを提案してください。

コンセプト:「工房」= 作業台の上に、作ったものと測った数字が並んでいる。
背景オフホワイト #FAFAF8、日本語が主役、抽象CGを使わず実物写真主義。
XR・デジタルツイン・AIの専門家の個人サイトだが、未来的な演出はしない。

出力してほしいもの:
1. アクセントカラーの候補3案（HEXと、なぜその色か）
2. 日本語Webフォントの候補3案（見出し用・本文用、Google Fonts優先）
3. 余白・グリッドの設計（コンテナ幅、カラム数、セクション間の余白）
4. 「白背景で安っぽく見えない」ための具体的なテクニックを5つ
5. 実物スクリーンショット（点群・3D都市モデル・エディタ画面）を、
   白基調のデザインに品よく載せるための扱い方

デザイン画像はまだ作らず、文章だけで答えてください。
```

## 使うときの注意

1. **日本語テキストは崩れる。** 画像生成は日本語の字形が壊れます。文字の可読性は無視し、
   **レイアウト・余白・色・ビジュアルの質感**だけを見てください。文言は Readdy 側で入れます。
2. **見るべきは3点** ── ①オフホワイトで安っぽくなっていないか ②ビジュアルが実物に見えるか
   ③Works が主役に見えるか
3. **うまくいかない時の追い足し文**:
   「もっと余白を増やして要素を減らしてください。装飾を全部取り、罫線と余白だけで構成してください。」
4. 気に入った案が出たら、その画像を **Readdy に参照画像として渡す**。
   [`readdy_prompt.md`](readdy_prompt.md) のテキスト指示と併用する。
